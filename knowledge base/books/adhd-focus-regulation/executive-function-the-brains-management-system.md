# Executive function — the brain's management system

**What executive function is, in plain terms.** Executive functions are the mental "management
skills" that let a person get things done: holding information in mind, planning, getting
started, organising, resisting distractions and impulses, keeping track of time, switching
between tasks, and monitoring how it's going. Think of them as the brain's air-traffic control
or the manager who coordinates everything else. Crucially, these skills are separate from
intelligence — a very bright child can have weak executive function and struggle to *deploy*
what they know. When a capable kid "should be able to do this" but keeps forgetting, losing
things, melting down over homework, or never getting started, weak executive function is usually
why.

**It develops slowly — into the mid-twenties.** These skills live largely in the prefrontal
cortex, the last part of the brain to mature. So *every* 6–10 year old has partial, patchy
executive function — and children who are more active or distractible are often running a few
years "behind" their age in these particular skills while being right on track, or ahead,
elsewhere. Expecting adult-level organisation and self-control from a child whose management
system is half-built is a recipe for frustration on both sides.

**The main executive skills, and what weakness looks like at 6–10:**
- **Working memory** — holding info in mind while using it. *Weakness:* forgets multi-step
  instructions ("get dressed, brush teeth, come down" → gets dressed, then wanders off);
  loses the thread mid-task.
- **Task initiation** — getting started. *Weakness:* not laziness but genuine "stuck at the
  starting line"; the child wants to but can't get going, and looks like they're avoiding.
- **Planning & organisation** — sequencing steps, keeping materials in order. *Weakness:* chaotic
  bag and room, no idea how to break down a project, always missing a piece.
- **Impulse control (inhibition)** — pausing before acting. *Weakness:* blurts out, interrupts,
  grabs, acts before thinking.
- **Emotional control** — managing feelings. *Weakness:* big, fast reactions to small setbacks.
- **Time management** — sensing how long things take. *Weakness:* "time blindness," always late,
  no feel for "five minutes."
- **Flexibility** — shifting plans. *Weakness:* thrown by changes and transitions.
- **Self-monitoring** — noticing how you're doing. *Weakness:* doesn't catch own mistakes,
  can't tell when off-track.

**The key parenting move: be their external management system — then hand it over slowly.** A
child with weak executive function can't just be *told* to be organised; the skills aren't there
yet. So at first *you* provide the missing functions from the outside — you're the working
memory (checklists, reminders), the planner (breaking tasks down), the clock (timers), the
organiser (a place for everything). Then, gradually, you teach and transfer each skill so the
child internalises it over years. This "scaffolding then fading" is how executive skills are
actually built — not by expecting them to appear, and not by doing it all forever.

**Practical ways to scaffold each skill:**
- **Working memory** → write it down, use visual checklists and routine charts, give one
  instruction at a time, have the child repeat it back.
- **Task initiation** → shrink the first step to something tiny ("just get the book out"), do
  the first bit *with* them, use a timer to start.
- **Planning** → break big tasks into a visible list of small steps; plan the sequence together.
- **Time** → make time visible (timers, clocks, "time how long teeth take"); give countdowns.
- **Impulse/emotion** → teach a pause ("stop and think"), practise calming routines in calm
  moments, name feelings.
- **Organisation** → a "home for everything," a launch pad by the door, regular bag/desk resets
  done together.

**Frame it with warmth, not shame.** A child who constantly hears "why are you so
disorganised/forgetful/careless?" learns to feel broken. Reframe it as a specific,
buildable skill: "Your remembering-muscle is still growing, so let's use a list to help it —
everyone's brain needs tools." You're on the same team against the problem, not against the
child.

**The one-line version.** Executive functions — working memory, getting started, planning,
impulse control, time sense — are the brain's slowly-developing management system, separate from
how smart a child is; when they're weak, be your child's external manager (lists, timers,
step-by-step, a place for everything) and hand each skill over gradually, with warmth rather
than blame.
