Momzo

Momzo is a Flutter + Supabase mobile app — a calm, 3-minute-a-day habit for busy mothers of 6–10 year-olds to learn about and bond with their child. Three things set it apart: per-child personalization, in-the-moment grounded AI help (RAG over a vetted expert corpus, with safety refer-out), and a two-sided parent↔child bonding loop including the kid wish wall. The core loop is a daily card + "why it matters", grounded AI Q&A, a shared question of the day, and gentle no-guilt nudges. The Phase 1 core loop and most Phase 2 depth features are built; the board now tracks the launch-readiness gate — COPPA, no-train AI, backups, and real email/auth — plus Phase 3 expansion calls.

How we work: raise an item ID in chat ("decide Q4", "add idea: …") and Claude updates this board — Open items move to Decided with the rationale kept. To reply: hit "Reply" on any card, pick a stance, write your message, attach files if useful, and Send — it starts a thread under that card. "＋ New topic" (top right) creates a card with its own thread under Team topics; "? Ask Claude" raises a question card Claude answers directly; "＋ Add note" parks an idea, suggestion, observation or reminder to discuss later (editable and deletable). While a Claude session is running on the host machine, Claude reads new messages as they arrive, posts answers into the same thread, and triages new topics; board updates (Open → Decided) follow. Start the board with planning\START-BOARD.cmd; team members on the office network open the LAN address the server prints — messages are attributed by machine name. On the shared artifact copy (no server), use the "Copy feedback" button and paste the text to Claude.

    ├─ Postgres 15  ·  RLS (cross-family isolation)  ·  pgvector(768)
    ├─ Auth (email + Google/Apple)  ·  Storage  ·  Realtime
    ├─ pg_cron (daily nudges, recap)  ·  consents audit + trigger
    └─ Edge Functions (Deno/TS) — hold ALL secrets
            │
            ▼
  AI providers (split — server-side only)
    ├─ Embeddings → Gemini  gemini-embedding-001 @ 768d
    ├─ Generation → Mistral  mistral-small → medium/large
    └─ RAG grounding · citations · safety refer-out · cost caps
            │
            ▼
  Push / external  FCM nudges (quiet hours)  ·  WhatsApp (Phase 2, cancelled)

      

        Edge Functions are the only place secrets live — the app never holds an AI key. Providers are
        split: the Google key's generateContent quota is 0, so embeddings run on
        Gemini and text generation on Mistral. Everything is verified to work on the Free tier
        (Supavisor transaction pooler on 6543, prepared statements off); the two Free-tier costs — no automated
        backups and 7-day inactivity auto-pause — are tracked as launch risks below.
